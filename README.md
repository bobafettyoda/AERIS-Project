# AERIS

**Assessment of Environmental Risk and Incident Siting** is a Maryland-focused geospatial screening and diligence platform for large infrastructure siting.

AERIS deliberately separates three questions:

1. **Regional suitability** — where in Maryland should an analyst investigate?
2. **Physical feasibility** — what real parcels and mapped land area remain after known constraints?
3. **Diligence risk** — what grid, zoning, planning, ownership, utility, and engineering questions remain unresolved?

It is a screening system, not a permit, engineering, utility-capacity, ownership, or investment-readiness determination.

## Current workflow

```text
Maryland 1 km statewide model
        ↓
Candidate zones
        ↓
Scoped statewide parcel acquisition
        ↓
Preliminary mapped-constraint envelopes
        ↓
Terrain, wetlands, road access, and parcel assemblages
        ↓
FAA aviation screening
        ↓
Public transmission/substation context
        ↓
Statewide planning and jurisdiction context
        ↓
Human due diligence
```

## Repository

```text
AERIS/backend     FastAPI API and geospatial pipelines
```

## Quick start in WSL

### Backend

```bash
cd AERIS/backend
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

### Frontend

```bash
cd AERIS/frontend
npm ci
npm run generate:api
npm run dev -- --host 0.0.0.0
```

Open `http://localhost:5173`.

## Validation

```bash
cd AERIS/backend
python -m unittest discover -s tests -v

cd ../frontend
npm run generate:api
npm run build
npm run lint
```

## Scoped parcel builds

Expensive parcel artifacts are built through explicit POST jobs rather than mutating GET requests.

```text
POST /analysis/parcels/build/zone/{zone_id}
GET  /analysis/parcels/jobs/{job_id}
GET  /analysis/parcels/scopes/{scope_id}/bundle
GET  /analysis/parcels/scopes/{scope_id}/parcels/{parcel_id}
```

Builds are protected by per-scope interprocess locks and GeoPackages are published atomically. Optional domains may fail independently; completed evidence remains available.

## Core safeguards

- Technical suitability is separate from equity and community-impact evidence.
- Hard environmental exclusions are not hidden inside weighted scores.
- Parcel availability and vacancy are never inferred as confirmed.
- A preliminary envelope is not confirmed buildable land.
- Transmission voltage and proximity do not establish available capacity.
- Missing planning/permit automation does not mean no restriction exists.
- FAA notice-distance screening is not an FAA determination.

## Data

Large downloaded and derived GIS artifacts are intentionally not stored in Git. Source snapshots and derived outputs are generated by the scripts under `AERIS/backend/scripts` and recorded through manifests/checksums.
